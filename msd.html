근골격계 유해요인조사

MUSCULOSKELETAL HAZARD SURVEY

공종 투입 시 근로자 2명의 작업 사진을 올리면 Claude가 OWAS·RULA·REBA 중 알맞은 도구로 평가하고, 현장 양식 엑셀과 평가 보고서(워드)를 만듭니다.

API 키 설정

사진 분석은 본인의 Anthropic API 키로 Claude를 부릅니다. 키는 이 브라우저에만 저장되고 홈페이지 코드나 GitHub에는 들어가지 않습니다. 분석 1건에 약 100~200원이 키 계정에서 결제됩니다.

API 키 받는 방법
  1. console.anthropic.com에 가입·로그인합니다. (Claude Pro 구독과는 별도입니다)
  2. 왼쪽 Billing에서 카드를 등록하고 크레딧을 충전합니다. 처음엔 5달러면 충분합니다.
  3. 왼쪽 API Keys → Create Key를 눌러 키를 만들고, 바로 복사해 위 칸에 붙여넣은 뒤 저장을 누릅니다.
  4. 연결 확인을 눌러 "연결 성공"이 나오면 끝입니다.

키는 비밀번호처럼 다루세요. 공용 PC에서는 다 쓴 뒤 키 지우기를 누르세요. 키가 노출된 것 같으면 console.anthropic.com에서 해당 키를 삭제하고 새로 만드세요.

새 조사 기본값 (사업장·현장·조사자)

조사 내용과 사진은 이 기기의 브라우저에만 저장됩니다. 사진 분석을 누를 때만 사진과 작업 정보가 Anthropic(Claude) 서버로 전송됩니다.
