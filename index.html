건강진단 사후관리

근로자별 검진 결과로 사후관리 상담지·예방 교육자료·상담 기록을 A4 3장으로 출력합니다.

취약근로자 관리대장

혈압·고령·개인질환·직업성질환 기준으로 취약근로자를 분류하고 채용 판정, 건강상담 주기, 작업 제한, 고령근로자 채용 요청서를 관리합니다.

경고표지 · 관리요령

MSDS PDF로 산업안전보건법 제115조 경고표지와 제114조 화학물질 관리요령을 만들어 인쇄합니다.

MSDS 관리대장

MSDS PDF를 올리면 성분·CAS·법적 해당 여부·위험물 지정수량을 정리해 엑셀 관리대장으로 내보냅니다.

현장 기상 모니터

현장 위치의 체감온도·미세먼지·자외선·오존 예보와 지난 기록, 카톡 공유 문구, 폭염·한랭 측정 기록부를 한곳에서 관리합니다.

보건 위험성평가

공종별 보건 유해요인과 MSDS 제품의 화학물질 위험성을 상·중·하로 평가해 현장 양식 그대로 엑셀로 내보냅니다.

근골격계 유해요인조사

공종 투입 시 근로자 작업 사진을 Claude가 OWAS·RULA·REBA로 평가하고, 현장 양식 엑셀과 평가 보고서(워드)를 만듭니다.

보건기준 핵심정리

산업안전보건기준에 관한 규칙 중 건설현장 보건 조문을 주제별로 요약하고 최신 원문으로 연결합니다.

입력한 내용과 올린 파일은 이 기기의 브라우저 안에서만 처리·저장되며 외부로 전송되지 않습니다. 현장 기상 모니터는 날씨 조회를 위해 현장 좌표만 날씨 서비스로 보냅니다. 근골격계 유해요인조사는 사진 분석을 누를 때 사진과 작업 정보를 본인 API 키로 Anthropic(Claude)에 보냅니다.
